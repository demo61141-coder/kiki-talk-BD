## অ্যাপের বৈশিষ্ট্য

- **ভয়েস সুইচ:** মডেল ১ — আকিব / মডেল ২ — কিকি বিগ রিরেকর্ড।
- **৩টা অপশন:** (a) শুধু অডিও, (b) অডিও + সাবটাইটেল (SRT, নির্ভুল সময়),
  (c) অডিও + স্ক্রিপ্ট → সাবটাইটেল।
- **স্ক্রিপ্ট যাচাই:** জেনারেটের আগে অ্যাপ নিজেই স্ক্রিপ্ট ঠিক করে দেয়
  (সংখ্যা বাংলা কথায়, কোলন→কমা, … বাদ, ।।।→।, বানানরীতি) আর কী বদলেছে দেখায়।
  "স্ক্রিপ্টের নিয়ম" পেজে নিয়মের টেবিল + কপি করার মতো তৈরি প্রম্পট আছে।
- **অ্যাকাউন্ট:** নাম + মোবাইল + পাসওয়ার্ড দিয়ে সাইন আপ; মোবাইল + পাসওয়ার্ড
  দিয়ে লগইন। পাসওয়ার্ড salted PBKDF2 হ্যাশে থাকে, কখনো প্লেইনটেক্সট নয়।
- **ফ্রি ট্রায়াল:** সাইন আপের পর ১ ঘণ্টা; কাউন্টডাউন দেখায়; শেষ হলে জেনারেশন বন্ধ।
- **সাবস্ক্রিপশন:** ৳৫০/মাস; অ্যাডমিন অ্যাপ্রুভের দিন থেকে ৩০ দিন আনলিমিটেড
  (দৈনিক ফেয়ার-ইউজ সীমা ২০,০০০ অক্ষর)।
- **ম্যানুয়াল পেমেন্ট:** অ্যাপে মালিকের বিকাশ/নগদ নম্বর দেখায় (এখনো
  `01XXXXXXXXX` প্লেসহোল্ডার — আসল নম্বর পেলে `app.py`-তে বসাতে হবে),
  Send Money নির্দেশনা, তারপর ট্রানজাকশন আইডি এবং/অথবা স্ক্রিনশট জমা।
- **অ্যাডমিন প্যানেল:** একই অ্যাপের ভেতরে (`?admin=1` বা সাইডবারের বাটন)।
  পাসওয়ার্ড প্রথমবার অ্যাডমিন নিজে সেট করেন (কোডে বা রেপোতে কোনো পাসওয়ার্ড নেই)।
  পেমেন্ট সাবমিশনের তালিকা (নাম, মোবাইল, TrxID, অ্যামাউন্ট, স্ক্রিনশট) —
  অ্যাপ্রুভ করলে ৩০ দিন চালু, রিজেক্টও করা যায়; ইউজারের তালিকা + মেয়াদের
  তারিখ; পাসওয়ার্ড রিসেট ও অ্যাকাউন্ট বন্ধ/চালু করা যায়।
- **ডেটা:** প্রাইভেট HF ডেটাসেট `demoqqq/kiki-talk-data` — Streamlit রিস্টার্ট
  হলেও মুছে যায় না, কোনো সার্ভার বা Google Cloud সেটআপ লাগে না।

## ডেপ্লয় — Streamlit (অ্যাপ)

1. https://share.streamlit.io → New app → রেপো `demo61141-coder/kiki-talk-BD`,
   branch `main`, Main file path: `app.py`।
2. **Settings → Secrets**-এ বসান:
   ```toml
   HF_TOKEN = "hf_..."   # Hugging Face টোকেন — demoqqq/kiki-talk-data ডেটাসেটে লেখার (write) অনুমতিসহ
   ```
   টোকেন ছাড়া সাইন আপ/লগইন/পেমেন্ট কিছুই চলবে না — অ্যাপ পরিষ্কার করে জানিয়ে দেবে।
3. প্রথমবার মডেল (১১৪ MB × ২) HF থেকে নামবে — প্রথম জেনারেশনে কয়েক মিনিট
   লাগতে পারে, তারপর cache হয়ে যাবে।
4. ডেপ্লয় হলে আসল Streamlit লিংকটি `landing/index.html`-এর ৫ জায়গায় থাকা
   `STREAMLIT_APP_URL`-এর বদলে বসিয়ে আবার পুশ করুন।
